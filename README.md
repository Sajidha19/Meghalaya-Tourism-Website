#  Meghalaya Tourism Website

A responsive tourism website showcasing the **natural beauty, tourist attractions, culture, and travel experiences of Meghalaya, India**.

## ✨ Features

* Responsive and user-friendly design
* Popular tourist destinations in Meghalaya
* Destination images and information
* Clean and attractive layout
* Easy navigation

## 🛠️ Technologies Used

* HTML5
* CSS3
